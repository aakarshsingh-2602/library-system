# Student Library Management System

A robust, console-based Library Management System built in C++ demonstrating core Object-Oriented Programming (OOP) principles and persistent data storage. Developed as a 2nd-semester B.Tech mini-project at AKGEC.

# Features
* **Inventory Management:** Add new books with unique IDs, titles, and author details.
* **Real-time Status Tracking:** Issue and return books with dynamic availability updates.
* **Data Persistence:** Utilizes C++ `<fstream>` to automatically save and load library data to a local text file (`library_data.txt`). No data is lost when the program closes.
* **Memory Efficient:** Built using `std::vector` for dynamic memory allocation, scaling automatically as the library grows.

# Tech Stack
* **Language:** C++
* **Concepts Applied:** Classes & Objects, Encapsulation, File Handling (I/O Streams), Standard Template Library (STL).
